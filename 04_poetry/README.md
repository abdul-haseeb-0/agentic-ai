# 🎵 Poetry: Python Dependency Management Simplified 🐍

Poetry is your go-to tool for managing Python dependencies and packaging projects. 🚀

---

## 📦 Key Features

- **Dependency Management:** Handles your Python packages with ease.
- **Virtual Environments:** Automatically creates and manages virtual environments.
- **Project Packaging:** Simplifies the process of building and publishing Python packages.

---

## 🛠️ Common Commands

```bash
# Initialize a new Poetry project
poetry init

# Add a dependency
poetry add <package-name>

# Install dependencies
poetry install

# Run your project
poetry run python <script.py>
```
