Rules For Naming Variable:

✔ A variable name must start with a letter or the underscore character _
✔ There must be no white space in a variable name
✔ A variable name cannot start with a number
✔ A variable name can only contain characters (A-Z, a-z, 0-9, and _ ). No special 
characters are allowed i.e. @icode , Python$ are the invalid variables.
✔ Variable names are case-sensitive (age, Age and AGE are three different variables)
✔ Keywords cannot be used as variable names.

Conditions:
If-Statements take a condition and only runs a block of code if the 
condition evaluates to True.
✔ Elif-Statements take a condition and only tests it if the prior 
If-Statement (and all prior Elif-Statements) evaluate to False. It 
is optional.
✔ Else-Statements take no condition and runs a block of code if the 
prior If-Statement (and Elif-Statements, if there are any) evaluate 
to False.
